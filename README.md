# FRONT ZÉRO

Original browser first-person shooter built with three.js: solo and multiplayer, several modes and maps.

- `index.html` and the `.js` modules are the game (no build step).
- `server/` is the multiplayer server (Node, WebSocket). Run it with `npm ci --prefix server` then `node server/server.js`.

Weapon recordings come from The Free Firearm Sound Library (CC0); sources are listed in `sounds/LICENSE.txt`.
